# Plural World — Portfolio

A portfolio site for a footwear/apparel designer and brand strategist, built with Vite, React, TypeScript, and react-router-dom.

## Pages

- `/` — Home
- `/works` — Works
- `/about` — About
- `/contact` — Contact

Content lives in `src/data/content.ts`. Project photos are placeholders (`src/components/ImagePlaceholder.tsx`) — swap them for real images.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
